1. Main Features
👤 Santo Login

દરેક સંત માટે login રહેશે.

Mobile/Email + Password
Admin login અલગ
સંતનું નામ/profile
પોતે upload કરેલી entries જોઈ શકે
📚 Book Entry

સંત કોઈ book વાંચે ત્યારે:

Book Name
Author
Publisher — optional
Book Cover — optional
Language — Gujarati / Hindi / English / Sanskrit
Book Category — optional

એકવાર book add કર્યા પછી એ book ફરીથી select કરી શકાય.

2. 📖 Topic / Vishay

Image upload કરતી વખતે:

Book: Vachanamrut
Topic: Bhakti
Page: 125
Image: uploaded image
Short Note: optional

Topics predefined રાખી શકાય:

Bhakti
Satsang
Seva
Vairagya
Dharma
Niyam
Guru Bhakti
Ekantik Dharma
Sadhuta
Ahimsa
Prarthana
Katha
Yuva
Bal Satsang

અને New Topic પણ add કરી શકાય.

3. 📸 Image Upload

સંત કોઈ topic વાંચે અને તેને useful passage મળે તો તેનો ફોટો upload કરે.

Example:

Book: Swamini Vato
Topic: Guru Bhakti
Page: 87
Image: 📷
Note: “આ વાત ગુરુભક્તિ વિશે ખૂબ સુંદર છે.”

એક topic માટે multiple images upload કરી શકાય.
